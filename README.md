# Tellcenter Portal Empleados 🏢

Portal web interno para la gestión operativa, control de horarios, inventario de activos tecnológicos, costos y soporte IT de los colaboradores de Tellcenter.

## 🛠️ Stack Tecnológico
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla SPA / Multi-page responsive).
* **Backend:** Node.js, Express.
* **Base de Datos & ORM:** SQLite / PostgreSQL con **Prisma**.
* **Seguridad:** Autenticación basada en JSON Web Tokens (JWT).
